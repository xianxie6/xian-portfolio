# 张弦 · 个人作品集

10 年 UX 产品设计经验，设计、开发与 AI 创作。

## 代表作品

- 清明上河：可漫游的宋代街市。
- 有解数学实验室：可操作的数学实验。
- 此刻在馆：虚拟展厅与交流体验。
- Mochi：独立设计、开发并上架的宠物陪伴 App。
- 邮票边缘 Skill：图片邮票边缘处理工具。
- 收好 · Little Order：3D 收纳互动。
- 行业知识体系工具：可复用的行业研究 Skill。

## 本地预览

直接打开 `index.html`，或运行：

```sh
python3 -m http.server 8080
```

支持手机浏览、作品筛选、案例详情、日夜切换和打印保存 PDF。
